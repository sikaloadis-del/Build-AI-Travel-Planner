# AI Travel Planner

Hackathon MVP for building a destination overview, attraction shortlist, stays, restaurants, map-style grouping, editable itinerary, and budget estimate from transparent research snapshots.

This first local version uses curated demo research packs to demonstrate the complete experience without live API credentials. The UI is structured so later Google Places, Maps, Booking, weather, and AI research providers can replace the demo adapters while preserving source labels, freshness, and disclaimers.
